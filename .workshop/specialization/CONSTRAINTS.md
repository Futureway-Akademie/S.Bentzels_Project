# Technische Rahmenbedingungen

- Keine Tracking-Tools, keine externen Schriften, keine Drittanbieter-Einbettungen ohne Einwilligung (DSGVO).
- 0 px Radius, keine Schatten, keine Verläufe. Kunstwerke nie beschneiden (`object-fit: contain`).
- Keine fest verdrahteten UI-Texte, alles über i18n.
- Platzhalterdaten liegen bis Phase 2 in `src/data/` und sind für Supabase typisiert.
- Der Name des exklusiven Netzwerk-Kreises ist offen (Arbeitstitel „Bentzel Club“) und wird nur an zentraler Stelle definiert, inklusive Routenkonstante.
- Die Überraschungsinterventionen der Module von „The Art of Becoming“ werden nicht detaillierter beschrieben als im Masterprompt.
- API-Schlüssel (Resend) nur als Supabase-Secret, nie im Code oder Chat.
- Preise immer als Endpreis „inkl. MwSt.“, kein Online-Kauf.

Diese Rahmenbedingungen ergänzen den zentralen Workshop-Workflow und dürfen ihn nicht überschreiben.
