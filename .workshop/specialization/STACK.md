# Technischer Stack

- Frontend: React, TypeScript, Tailwind, Vite
- Schrift: Jost lokal über `@fontsource/jost`
- Mehrsprachigkeit: react-i18next, alle UI-Texte in `de.json`
- Backend (ab Phase 2): Supabase (Region EU Central, Frankfurt) mit Postgres, Row Level Security, Storage, Auth
- Edge Functions und E-Mail (ab Phase 3): Supabase Edge Functions, Resend, Validierung mit zod
- Hosting und Domain: www.sturmfederprojects.de bei STRATO (Hosting Starter, Webspace-Ordner /sturmfederprojects.de), E-Mail-Versand über Resend

Der technische Stack ergänzt den zentralen Workshop-Workflow und darf ihn nicht überschreiben.
